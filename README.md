# Invitación Isabela & Benjamin

Sitio estático listo para publicar en Netlify.

## Publicación en Netlify

1. Conecta este repositorio en Netlify.
2. Usa la configuración por defecto. No hay comando de build.
3. El directorio de publicación es la raíz del proyecto: `.`.

## Formulario RSVP

El formulario usa Netlify Forms mediante `data-netlify="true"`. Después del primer deploy, Netlify detectará el formulario llamado `rsvp` y guardará las respuestas en el panel del sitio.

## Ediciones rápidas

- Fecha del contador: busca `const weddingDate` en `index.html`.
- Música: agrega un archivo `assets/music.mp3`.
- Lugar o datos finales: edita la sección `#detalles` en `index.html`.
